# 0.22.0.dev22

Adds `connectors serve --config` for an external OAuth MCP connector using the
official SDK Streamable HTTP transport and existing protected operation owners.
Browser consent verifies the configured owner at Cooper Authelia; operator versus
restricted mode, scopes, environments and restricted actions are explicit. Existing
DCR/PKCE/code/token/refresh/revocation authority is reused; no new token cryptography.

Canonical tool discovery respects current grants and separate content/input scopes.
Stateless authenticated requests retain existing original-effect custody. Existing
stdio and local controller contracts are preserved. No provider turn, production
grant, native daemon upgrade or OpenAI account installation follows from server
startup. See docs/agents/external-oauth-connector.md for the private policy and
separate source/installed/external/account acceptance boundaries.
