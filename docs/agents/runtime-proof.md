# Runtime proof

Source, installed identity, availability, acceptance and publication are separate
boundaries. Verify the installed executable or direct MCP/service surface before
claiming its behavior. Use isolated fixture roots for reproductions; preserve
production state, other sessions, workers and pending intent. Label injected
provider evidence explicitly. Inspect current runtime without exposing credentials.
No source change or triage state authorizes live dispatch or recovery. Record
unknown outcomes; reconcile before retries. Do not substitute guest wall time
for an unqualified trusted clock.

Local-operation protective interrupts retain versioned ownership evidence in the
existing private turn-collector journal. Only a qualified real acknowledgement
or unique original client-message reconciliation publishes this evidence. It
binds the admission fingerprint, payload/target digests, endpoint and original
nonempty turn ID. The consumer rechecks the original peer/process/image/home and
socket generations, then journals one exact interrupt attempt. Its retained
kernel I/O fuse is only an abort mechanism, never time or permission authority.
Missing evidence cannot be manufactured during clock loss. Ordinary RPC and
caller authorization gates remain strict. An interrupt acknowledgement means
requested; rejection, disconnect or fuse cutoff remains uncertain without replay.
Terminal native evidence is separate, and this path neither pauses goals nor
establishes autonomous-goal containment or installed Native acceptance.
