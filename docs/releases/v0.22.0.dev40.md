# 0.22.0.dev40

Persisted tab-monitor freshness now uses authenticated Stable Time counter
continuity instead of guest wall-clock subtraction. Wall clock rollback no longer
invalidates a recent frame when qualified elapsed evidence remains continuous.

Missing clock evidence, counter rollback, changed epoch/frequency and invalid
rate remain stale. Old snapshots remain readable but require a new observation
to gain freshness. age_seconds is a conservative upper bound or null when
continuity is unknown; freshness_basis explains the selected outcome.

Native expiry enforcement #695 and broad timer migration remain separate. The
current Grok release is retained; this package does not replace native Codex.
